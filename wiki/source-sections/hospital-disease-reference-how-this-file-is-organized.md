## Extract

The file is organized around practical hospital reasoning:

- disease profiles
- symptom relationships
- warning signs
- common investigations
- department routing
- overlapping conditions

A symptom can connect to many diseases. A test can support an evaluation pathway but does not automatically confirm a disease. Department routing depends on severity, age, risk factors, pregnancy status, vital signs, examination, and test results.
